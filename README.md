# Udaya Sri - Portfolio (React + Vite)

## Run locally
    npm install
    npm run dev        # http://localhost:5173

## Build
    npm run build      # output in dist/

## Deploy
- **Vercel:** push this folder to GitHub, then Import Project on vercel.com. Framework: Vite, build `npm run build`, output `dist`.
- **Netlify (drag and drop):** run `npm run build` and drag the `dist` folder onto app.netlify.com/drop (a ready-made `dist` is already included).
- **GitHub Pages:** push to GitHub, run `npm run build`, and publish the `dist` folder (the config uses relative paths).

## Edit your content
All text, links, certificates and academics are in `src/App.jsx`. Images are in `src/assets/`.
